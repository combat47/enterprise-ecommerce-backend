# Enterprise Ecommerce Backend

Production-ready marketplace backend built with Java 21 and Spring Boot.

## Architecture

This project follows:

- Modular Monolith
- Clean Architecture principles
- Hexagonal Architecture concepts
- Domain Driven Design concepts

## Main Technologies

- Java 21
- Spring Boot
- PostgreSQL
- Redis
- Kafka
- Docker
- Testcontainers
- Flyway
- Prometheus
- Grafana

## Business Domains

- Identity
- Catalog
- Inventory
- Cart
- Order
- Payment
- Shipping
- Notification
- Seller Management
